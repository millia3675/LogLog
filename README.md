# LogLog

AI 대화와 여러 문단의 글을 붙여넣어 PNG 이미지로 만드는 독립 웹 편집기.

- **사용 주소:** https://millia3675.github.io/LogLog/
- **연동·가입 없음:** RISUAI 없이 일반 텍스트로 사용합니다.
- **하단 정보:** 봇, 모델, 자유란을 각각 입력하거나 숨길 수 있습니다.
- **본문:** 굵게, 기울임, 굵은 기울임, 인용구, 빈 줄, 단어 치환 및 되돌리기.
- **대사 강조:** 디자인 → 대사 강조에서 형광펜 배경을 켜고 끌 수 있습니다. `"대사"`, `“대사”`처럼 짝이 맞는 큰따옴표 안을 사각 배경으로 표시합니다. 색상 변경, 여러 줄·여러 페이지 대사, 스타일 저장을 지원합니다. 기본값은 꺼짐이며, 대사 글자색은 강조 배경과의 대비에 맞춰 자동 선택됩니다. 닫히지 않은 따옴표와 작은따옴표는 강조하지 않습니다.
- **디자인:** 6가지 기본 스타일, 단색·그라데이션·사진 배경, 그레인·별빛, 오버레이, 8가지 한글 글꼴, 글자 크기·줄 간격·빈 줄 간격·정렬·여백·모서리.
- **내 스타일:** 브라우저에 저장, 이름 변경, 삭제, JSON 가져오기·내보내기. 사진은 스타일 파일에 포함하지 않습니다.
- **출력:** 720px 또는 1440px 너비의 PNG. 한 장으로 길게 또는 여러 장으로 나누기. 여러 장은 ZIP으로 내려받습니다. 지원하는 브라우저에서 시스템 이미지 공유를 제공합니다.

## 로컬 실행

별도 빌드나 패키지 설치가 필요하지 않습니다. 이 폴더에서 아래 명령으로 실행합니다.

```sh
python -m http.server 4173
```

브라우저에서 http://localhost:4173 을 엽니다. `index.html`을 직접 열 수도 있지만 브라우저의 로컬 파일 접근 정책에 따라 웹폰트나 저장 기능이 제한될 수 있습니다.

## GitHub Pages

이 파일들이 저장소 루트에 위치하도록 커밋합니다. 저장소 Settings → Pages → Source에서 **GitHub Actions**를 선택하면, `main`에 반영할 때 `.github/workflows/pages.yml`이 사이트를 배포합니다. 상대 경로만 사용하므로 `/LogLog/` 같은 하위 경로에서도 작동합니다.

## 개인정보와 제한

본문, 하단 정보, 사진은 앱에서 서버로 전송하지 않습니다. 본문과 사진은 새로고침 시 사라지고, 마지막 디자인과 내 스타일만 localStorage에 보관합니다. 기기 간 동기화는 하지 않습니다. 호스팅 제공자는 일반적인 웹 요청 정보를 처리할 수 있습니다.

- 본문 최대 60,000자, 사진 최대 20MB(PNG/JPG/WebP).
- 한 장은 기본 좌표 기준 최대 12,000px 높이. 초과 시 여러 장 나누기를 선택합니다.
- 분할 이미지는 기본 좌표 기준 최대 1,200px 높이, 최대 80장입니다. 긴 문단은 줄 단위로 이어집니다.
- 사진은 가운데를 기준으로 배경에 꽉 차게 맞춰집니다.
- Markdown 전체를 지원하는 편집기는 아닙니다. `**굵게**`, `*기울임*`, `***굵은 기울임***`, 줄 시작의 `>` 인용을 지원하며 HTML은 텍스트로 처리합니다.
- 스타일 JSON은 LogLog 고유 형식입니다. 기존 플러그인의 JSON 파일과는 호환되지 않습니다.

## 구성

`index.html` 접근 가능한 편집 화면 / `styles.css`, `tokens.css` 반응형 디자인 / `engine.js` 텍스트 조판·Canvas 출력·ZIP 생성 / `app.js` 편집 동작과 스타일 관리.

기존 플러그인의 기능을 참고해 독립적으로 작성했습니다. RisuAI 코드, 로고, 리디의 사진이나 문구를 복사하지 않았습니다. 초기 본문은 이 사이트용으로 작성한 예시입니다.

## 글꼴

눈누에서 소설·AI 대화의 본문용 글꼴을 선별해 **리디바탕, 고운바탕, 프리텐다드, SUIT**를 추가했습니다. 신규 사용자의 기본 글꼴은 리디바탕입니다. 기존에 저장한 글꼴 설정과 스타일은 유지됩니다.

기존 Noto Sans KR, Noto Serif KR, Jua, Nanum Gothic Coding도 계속 선택할 수 있습니다. 추가 글꼴은 눈누에 안내된 WOFF/WOFF2 파일을 그대로 포함하며, 기존 글꼴은 Fontsource 5.3.0의 한국어 WOFF2 파일을 사용합니다. 모두 SIL Open Font License 1.1로 배포됩니다. 선정 기준과 원본 출처는 [글꼴 안내](FONTS.md), 저작권 고지와 라이선스 전문은 `fonts/OFL-*.txt`를 참조하세요. 글꼴을 재배포할 때 라이선스 파일을 함께 유지해야 합니다.
